# HardKit

A toolkit for automating the hard side of software development — writing, reviewing, and refactoring code.

HardKit is a Claude plugin for hands-on implementation work: writing features, reviewing diffs, tracking down bugs, and reshaping code that's grown awkward.

Its counterpart, [SoftKit](https://github.com/khs3994/SoftKit), handles the planning and communication around it.
